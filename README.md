# DocPilot

Agente de perguntas-e-respostas sobre documentacao tecnica, construido com
RAG (Retrieval-Augmented Generation), LangGraph, Qdrant, e um guardrail
deterministico de confianca que recusa responder quando o retrieval nao
tem cobertura suficiente para a pergunta.

Work in progress — see commit history for development progress.
